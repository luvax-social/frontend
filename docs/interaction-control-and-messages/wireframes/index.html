2. Mute dialog

P1-A2-R5
  • Opened from the post menu or the profile menu; both scopes are independent toggles that save on change, the same pattern as notification settings.
  • The copy says plainly that the other person is not told, and where muted content still appears.
  • Turning both toggles off is the unmute; there is no separate unmute button to keep in sync.

7. Post detail - hidden comments (owner only)

P1-D1-R6 P1-D1-R7 P1-D5-R4
  • The owner opens "hidden comments" from the post menu; the comment column swaps to the review list with a back control, so the media stays in view.
  • Each row names why it was hidden (one of your hidden words, limited interactions) and offers unhide and report.
  • Commenters never see any of this; their own hidden comment renders like any other comment in their view.
  • The post menu trigger sits at the right edge of the side column, so its menu flips to open leftward; this is the fallback case of the right-first rule.

11. Reactions and reply quotes

P1-B1-R1 P1-B1-R2 P1-B1-R5
  • Hovering a bubble reveals react and reply controls; react opens a pill picker with six quick reactions and a "more" input that accepts any single emoji.
  • The caller's current reaction is highlighted; choosing it again removes it, choosing another changes it. Reactions sit as a small chip under the bubble's edge.
  • Quotes come from the server preview, so a reply to an old message renders without loading history; a deleted or removed parent shows "message unavailable". Tombstoned bubbles show no chip and no picker.
